## 待优化项（2026-09-17 收尾：W1–W3、W5 已结案，W4 条件触发；Biview M1 移至新项目）

### W1 腰部解锁策略过粗（`--waist free` 一次放开 3 关节）
- **现象**：只要 `--waist free`，偏航/俯仰/侧展三关节全部进入变量空间，规划器为最优化路径误差会随意动腰。
- **期望语义**：腰要慎动——只有工作空间确实无解时才作为"救急自由度"使用：
  - **偏航（yaw）**：水平旋转，风险低，工作空间扩展优先用它；
  - **俯仰（pitch）/ 侧展（roll）**：改变躯干姿态，只有弯腰抓取等复杂任务才需要，**默认锁死**。
- **候选方案**：① 粒度化 `--waist yaw|pitch|roll|free|fixed`（多选），profile 里带各关节的启用代价（软权重/限幅），让 Descartes/DLS 优先用臂、懒用腰；② 或分级默认：`free` 语义收敛为"yaw free + pitch/roll 锁"，现有全自由改 `--waist all`。
- **✅ 结论（2026-09-17 已实施，方案② + 真降维）**：`--waist` 取 `fixed`（默认）/ `free`（只放 yaw）/ `all`（三关节，原 free 语义）。锁定机制选**真降维**（非活跃腰移出 `var_names`，而非限位夹死），理由：DLS 不再为被锁关节浪费步长、零空间真实减少。**救急语义不做自动解锁**（只由 `--waist` 显式决定，避免隐式行为）。**软权重方案（候选①）延后**：技术落点在 `make_finger_ik` 正则项一处（改 `λ²I` 为 `λ²·diag(W)`），但需调参且 profile 要新增权重字段（字段集即契约，须走评审）。实测 yaw-only 腰幅度 0.143 rad、perr 0.0004 mm，优于 all 的 0.436 rad（roll 顶 ±25° 限位）、0.0028 mm。**✅ 遗留已闭环（2026-09-17 免实机，用户决定）**：RViz 可视化 + 离线量化（主指/多指联动 × free/all 对比）确认"只放 yaw"够用——多指联动 `free` 档 ALL PASS、无腰协商、副指随动 ≤0.002 mm、左臂最小裕度 +0.118~0.164 rad（≈6.8°~9.4°，详见执行记录"收尾"行与 W5 量化表）。

### W2 both+free 左手轨迹不跟随（腰共享 vs 冻结腰假设矛盾）
- **现象**：双臂 + `--waist free` 时，左手完全没有跟准理想轨迹（右手正常）。
- **根因**：物理腰只有一套，但 B1 设计是"腰归右臂"——右臂规划逐帧动腰，左臂的腰却被 `frozen_waist_setter` **冻结在右臂首航点的镜像值**（demo `plan_fn`，`WAIST_MIRROR * Q[0]`）。左臂 IK 在"腰恒定"假设下求解，物理腰实际随右臂运动 → 左指尖偏离理想路径。回归未暴露：左臂在其自身（冻结腰）假设下自洽，golden 只守护规划口径。
- **候选方案**：
  1. **逐帧冻结**（改动最小）：左臂对右臂轨迹逐航点重规划，每帧冻结腰 = 该帧右臂腰的镜像（改动点在 `plan_fn`/`regression` 的时序：右臂整条先出，左臂按帧注入腰值）；
  2. **腰分配居中**（Phase C leader-follower 思路复活）：腰目标 = 双臂各自的腰需求按策略合成（如右臂主用、或取两者可行域交集中心）；
  3. **代价惩罚**（配合 W1）：腰运动进代价函数，右臂少动腰，从源头减小两臂腰冲突。
- **依赖关系**：W1 的粒度化策略是 W2 方案 3 的前置；W2 方案 1 可独立先做。
- **✅ 结论（2026-09-17 已实施）**：真实根因比原分析多一层——除了"左臂首帧冻结"，注入的还是**镜像腰**（`WAIST_MIRROR ⊙ w_r`）。物理腰只有一套，镜像注入让规划口径自洽但按真实腰执行偏差达 **109 mm（440 mm/rad）**；改成物理腰后自洽=物理=0.005 mm。实施内容：① 左臂逐帧注入**物理腰**（非镜像）；② 新增 `freeze_waist` 开关（`_HandAssembly` → 3 个 ModeStrategy → `build_cfg`/`build_cfg_multi`），让**任意侧**都能"以已知腰求解"，"腰归右臂"不再是硬编码；③ 两臂时间轴取 TOTG **逐点 max**（对齐且不违反任一侧限速）；④ `configure` 拒绝"单臂 + 腰动"（腰是共享关节，动腰必然改变两臂基座）；⑤ `frozen_waist` 记账退化为 `None`（腰已在 `positions` 腰列）。**遗留**：基线重捕、契约登记。
- **⚠️ 已废弃口径**：`WAIST_MIRROR` 与 `frozen_waist_from_vars` 已删除并留反面警示——镜像只适用于目标路径与 IK 种子，**不得用于腰**。

### W3 轨迹求解速度（协商路径是唯一风险点）

- **改造前基线（单形状规划耗时，s）**：`right-full-fixed` 2.59 合计（circle 0.78）/ `both-full-fixed` 6.36（2.06）/ `both-full-free` 7.48（3.03）/ `both-fixed-all` 9.45（4.11）。
- **改造后分项实测**：右臂 Descartes 72 点 ~2.2 s（不变）；左臂逐点求解 72 点 **~2.1 s（30 ms/点）**；左臂自碰撞扫描 ~0.7 s（2.4 ms/次 × 288）；协商（仅失败帧触发）**最坏 ~0.72 s/帧**（12 候选 × 2 臂 × 30 ms）。
- **推算**：快路径（左臂一次跟随成功）≈ **5–6 s/形状**（约改造前 1.2–1.5×，**落在 golden 1.5× 阈值内**）；协商路径（`both fixed all` 的 circle 修 23 帧）可能 **15–25 s/形状**。
- **根因**：`make_finger_ik` 用**有限差分雅可比**——每次迭代 `n+1` 次 FK（n=8~11），这是 30 ms/点的来源；逐点求解、协商、扫描全都建在它上面。
- **候选手段（按性价比）**：
  1. ✅ **已做（2026-09-17）解析雅可比——且免新增 tesseract 接口**：`env.setState` 取回的 `link_transforms` 本就含全部 93 个连杆（含各关节坐标系），所以**一次 FK 就同时给出 tip 位姿与所有关节轴位姿**，非耦合变量的雅可比列由「关节轴 × 连杆位姿」直接构造，每迭代 FK 次数由 `(1+n)` 降为 `(1+k)`（k = 耦合列数，通常 1）。原计划走 `getJointGroup`+Jacobian API，探针发现不需要——既不动防腐层，也免去新接口可用性风险。
     - 实测每迭代 1.886 ms → 0.264 ms（**7.2×**），单次 IK 47 ms → 6.6 ms；
     - 16 组合规划总耗时 108.9 s → 83.0 s（**↓24%**），重组合 `both-fixed-all` 21.6 → 12.8 s（**↓41%**）；单形状 circle 自最初 23.6 s 降至 6.0 s（**↓74%**）；
     - **耦合列必须走差分**：URDF 的 `<mimic>` 写在**从动**关节上（distal 跟随 prox），判据须为「自身被 mimic 驱动 **或** 驱动了别的 mimic 关节」。首版只判前者，导致 `right full fixed` 预检误报，已修正（见 `urdf_joint_frames`）；
     - 等价性：与数值雅可比 `max|Jn−Ja| = 1.9e-7`（即 `h=1e-6` 前向差分的截断误差量级）；重捕后轨迹漂移 Q ≤ 1.9e-6 rad、ts ≤ 1.8e-6 s、**points 逐元素完全相同**，perr 量级不变（0.0091448 → 0.0091459 mm）。验证脚本留存 `tests/probe_fk_jac.py`。
  2. ✅ **已做（2026-09-17）协商候选剪枝——用腰序列连续性**：`negotiate_waist` 在"原腰不合格"后先试**候选 0 = 上一修正帧最终采用的腰**（腰本就该连续、相邻帧腰需求相近）。实测 `both fixed all` 的 23 个需改帧中 **21 帧一个候选即命中**，省掉整轮 12 候选搜索（协商 IK 调用约 ↓83%）。连带收益：腰更平滑 → TOTG 执行时长 7.94→5.38 s（↓32%）；`both-fixed-all/circle` 规划耗时 **23.6→12.6 s（↓46%）**；两臂 perr 0.0091/0.0098 mm 保持。**注**：原计划的"只搜贴限位关节 / 4 档改二分"被更有效的连续性候选取代，未采用。
  3. ~~协商判据直接用 `make_finger_ik` 的 `e_norm`（省掉回算 FK）~~ **撤回**：原估"~30%"有误——`solve_frame` 回算的那次 FK 约 1 ms，而单次 IK 约 30 ms，占比仅 ~3%，不值得做。
  4. 自碰撞扫描细分 4 → 2：收益 ~0.35 s/臂（对 12.6 s 的路径约 3%），但会**放松碰撞检查粒度**，性价比不足，暂不做。
- **顺序结论**：**W3 候选手段全部结案**——1（解析雅可比）、2（协商候选剪枝）已完成，3 撤回、4 不做。
  累计效果（`both-fixed-all` 的 circle 单形状）：**23.6 s → 5.5 s（↓77%）**。

### W5 左臂腕关节贴限位（零空间裕度优化）

- **现象**：`both + 腰动` 时左臂 `arm_16`（腕）关节裕度恒为 **+0.000 rad**（贴限位），右臂同部位健康（`+0.079`）。位置误差 0.0046 mm、姿态误差 0.001° 均达标，所以**现有判据看不见它**。
- **三点定性（均已实测）**：
  1. **与腰无关**：腰取常值 0 / 0.05 / 0.10 / 0.143 / 0.20（`free` 档扫 yaw）时 `arm_16` 一律为 0.0000——**连完全对称的零腰基准也贴限位**；
  2. **不是不可达**：极限位置下位置/姿态误差仍在 0.005 mm / 0.001° 量级；
  3. **是零空间解选择问题**：7-DOF 臂对 6-DOF 任务有 1 维冗余，存在大量等效解；而 `make_finger_ik` 的正则项是 `λ²I`（"步长最小"），**从不考虑"离限位多远"**，解因此落到边界上。旁证：右臂在 `freeze_waist` 模式下（换种子与求解路径）裕度从 +0.000 → **+0.242 rad**，同一腰序列、同一目标。
- **全组合离线量化（2026-09-17，`tests/probe_joint_margin.py`）**：直接由 golden 的 `Q` + URDF 限位算各关节到最近限位的裕度，**768 项 = 16 组合 × 形状 × 侧 × 关节**，**无需真机**（Q 已在 `tests/golden/*.npz`）。左臂逐组合最小裕度（deg，顺序 `arm_11..17`）：

  | 组合 | arm_12 | arm_14 | arm_15 | arm_16 | arm_17 |
  |---|---|---|---|---|---|
  | `both-fixed-fixed` | 43.2 | 16.8 | 19.5 | **26.1** | 51.2 |
  | `both-fixed-free` | 9.5 | 25.3 | 14.7 | **0.00** | 20.6 |
  | `both-full-free` | **1.10** | 26.1 | **4.02** | **0.00** | 39.2 |
  | `both-fixed-all` | 22.0 | 21.3 | 19.8 | 13.1 | **9.28** |

  要点（补充上面定性，不改变其结论）：
  1. **触发面收敛到 `free`**：腰全锁（`fixed`）时左臂 7 关节最小裕度 **16.83°**（健康）；
     `free`（yaw-only）时 `arm_16` 归零。与定性 1 一致——**是"腰成为变量"这件事本身
     改变了求解路径**，而非某个腰值不够（free 档内对腰值不敏感）。
  2. **不只 `arm_16` 一个受害者**：`both-full-free` 下 `arm_12`（肩 roll）只剩 **1.10°**、

     是"左臂整体被压"，不是单关节巧合。
  3. **另有一处独立贴限位**：`all` 组合下 `waist_32`（腰 roll）裕度 **0.00°**（即 W1 已知的

  4. 复现：`python3 tests/probe_joint_margin.py`（纯离线、只读、不依赖 ROS/tesseract）。
     列布局 `7 = 臂7`、`9 = 臂7+手2`、`12 = 腰3+臂7+手2`（脚本内含左右腰列相等校验）。

- **候选手段（按性价比）**：
  1. **多种子重试取裕度最大者**（首选）：已有 `mirrored_seed`/链式种子双候选的框架，扩成"多个种子都解一遍、取 min 裕度最大者"——最便宜，且已被旁证有效。按量化结果可做成**条件触发**（先解一次，仅当 min 裕度低于阈值才换种子重试），平均开销很小；W3 把 IK 提速后重试的单位成本已大幅下降。
  2. **DLS 代价加限位排斥势**：`dx = solve(JᵀJ + λ²I, Jᵀe − k·∇(1/margin))`，把"离限位距离"写进目标。系数可先做成模块常量（与 `IK_LAM` 同级），**未必要动 profile 字段**——若日后需按机型调参再考虑入契约。
  3. **解出后沿零空间投影优化裕度**（理论最干净，改动最大）。

- **最终结论（2026-09-17，停止优化）**：B（裸 IK 种子重试取最大裕度）实测**引入碰撞回归**
