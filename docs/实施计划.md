## 步 0：golden 基线固化

**判据（入口无关，N8）**——基线文件对每个组合（arm/mode/waist/fingers）记录：
- 每形状×每侧：`Q`（关节轨迹，逐元素）、`ts`（时间戳）、`points`（理想路径）、
  `perr/dev`（主指误差 mm）、副指随动误差、规划耗时
- 组合级：waist span、过渡轨迹帧数、TOTG 时间戳有无
- 全局：`tesseract-robotics-nanobind` 实装版本（importlib.metadata 实测）、
  **ACM 内容 hash**、判据阈值（perr 0.1 / 离面 0.5 / 副指 0.5 / 中心四点预检）
- 时间戳容差单独标注（步 1 重建 program 路径放宽 1e-6 相对量级）

**任务**：
- 0.1 实测记录 nanobind 装机版本 → `tests/golden/manifest.json`
- 0.2 写 `tests/golden_capture.py`：复用 regression.py 的进入路径（sys.argv
  过渡期方案），逐组合逐形状规划，落 NPZ + manifest
- 0.3 ACM hash：`fix_allowed_collisions` 后从 env 读允许对集合，排序拼接
  SHA-256（读 API 若不存在则经 contact manager 对集重建）
- 0.4 全量实跑 19 组合，`RESULT ... ALL PASS` + 基线文件入库

**注意**：基线捕捉期间用 `python -u` + 输出重定向；泄漏/nanobind 告警为良性，
过滤条件不变。

## 步 0.5：入口参数化（消除 import 副作用）

**任务**：
- 模块级 `ARGS = _parse_args()` 及派生常量（`MODE/FINGER_NAME/SIDES/...`）
  全部移入 `main(argv=None)` / `build_context(args)`；模块只留真常量
  （FINGERS 耦合表、FRAME 等）
- 描述路径 `URDF/SRDF` 改为 `os.environ` 缺省 + 函数参数可传入（重写器实现
  仍归步 4，N7 切分）
- `tests/regression.py` 与 `golden_capture.py` 改为直接调 `build_context()`
  传参，不再篡改 `sys.argv`
- demo 入口 `if __name__ == "__main__"` 保持行为不变

**验收**：`golden_capture.py`（改 API 调用后）对照步 0 基线——positions 逐元素
全等、ACM hash 一致、ts 容差内；19/19 ALL PASS。
